# hdd-test — проверка сервера и диска перед покупкой

Один скрипт `vps-check.sh`: арендовали VPS или выделенный сервер и хотите понять, не обманули ли с дисками, процессором и сетью,
прежде чем платить за год. Ничего не меняет в системе
(кроме установки утилит при `--install`) и убирает за собой тестовые файлы.
