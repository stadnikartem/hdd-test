# hdd-test — проверка сервера и диска перед покупкой

Один скрипт `vps-check.sh`: арендовали VPS или выделенный сервер и хотите понять, не обманули ли с дисками, процессором и сетью,
прежде чем платить за год. Ничего не меняет в системе
(кроме установки утилит при `--install`) и убирает за собой тестовые файлы.

## Что проверяет

| Блок | Что смотрит | Зачем |
|---|---|---|
| Система | ОС (Debian 12/13, Ubuntu 22.04/24.04), архитектура, тип виртуализации (KVM или контейнер), systemd, TUN, WireGuard | панель ставится на эти системы; в контейнерах (OpenVZ/LXC) часть функций не работает |
| Процессор | скорость одного ядра, масштабирование по ядрам, **steal** (сколько времени у вас отбирают соседи), AES-NI | выявляет перепроданные ядра |
| Память | объём и скорость | минимум 1 ГБ, комфортно от 4 ГБ |
| Диск | последовательные запись и чтение, случайное чтение и запись 4K, число fsync в секунду (fio) | лента «Фото» упирается в случайное чтение, база — в fsync |
| Сеть | публичный IPv4, пинг до ya.ru/vk.com/GitHub, потери пакетов, скачивание и отдача, доступность GitHub, Debian, pypi, Docker Hub, Telegram | для просмотра фото и видео нужна хорошая отдача; из некоторых датацентров часть сервисов закрыта |
| Видео | кодирование 1080p через ffmpeg | миниатюры и поиск похожих фото |

В конце — сводка `OK / WARN / FAIL` и вердикт: «подходит», «можно, но есть слабые места» или «не брать».

## Запуск

Нужен root (`sudo`) и Linux с `apt` (Debian/Ubuntu). Самый короткий способ — одной командой:

```bash
curl -fsSL https://raw.githubusercontent.com/stadnikartem/hdd-test/main/vps-check.sh | sudo bash -s -- --install
```

Либо скачайте и запустите, так удобнее добавлять параметры:

```bash
curl -fsSLO https://raw.githubusercontent.com/stadnikartem/hdd-test/main/vps-check.sh
chmod +x vps-check.sh
sudo ./vps-check.sh --install --dir /mnt/data --need 1800
```

Если `curl` нет: `sudo apt-get install -y curl`. Результат можно сохранить в файл: `sudo ./vps-check.sh --install 2>&1 | tee check.txt`.

### Параметры

| Параметр | Что делает |
|---|---|
| `--install` | поставит недостающее через apt: `fio`, `curl`, `python3`, `ffmpeg`, `iproute2` (без `fio` диск проверяется упрощённо через `dd`) |
| `--dir ПУТЬ` | где тестировать диск. **Укажите папку на том диске, где будут лежать файлы** (по умолчанию `/var/tmp`) |
| `--need ГБ` | сколько свободного места должно быть (по умолчанию 900 ГБ); меньше — `FAIL` |
| `--size 2G` | размер тестового файла (по умолчанию 2 ГБ) |
| `--quick` | короткий прогон за 2–3 минуты (вместо 5–6) и файл 512 МБ |
| `--no-net` | пропустить сетевые проверки |

Для надёжного результата лучше запускать на «чистом» сервере, пока на нём ничего не работает, и повторить в другое время суток:
на VPS диск и процессор делят с соседями, поэтому один замер может быть удачным или неудачным.

## Как читать результат

- **Steal** выше 3% — процессор делят с другими, выше 10% — плохо.
- **Масштабирование по ядрам** ниже 80% от идеала — ядра общие.
- **Диск, HDD:** последовательные 80–200 МБ/с, случайное чтение 100–200 IOPS — нормально. SSD/NVMe — тысячи IOPS.
  Если последовательная скорость ровно одно и то же число (например, 20 МБ/с на чтение и запись), скорее всего, у тарифа стоит **лимит** — спросите хостера.
- **fsync** ниже 30 в секунду — база и поиск будут тормозить; нужен SSD под систему.
- **Скачивание и отдача:** хорошо от 80 Мбит/с; для просмотра фото и видео из дома важна именно отдача.
- **Telegram недоступен** — не ошибка скрипта: из части российских датацентров он закрыт; Thin Web ходит в него через прокси, если он включён.

Скрипт не проверяет то, что есть только в договоре: лимит трафика и скорость порта, надёжность диска (RAID), поддержку.

## Если что-то не работает

- `fio: command not found` — запустите с `--install` или поставьте `sudo apt-get install -y fio`.
- Сеть «нет ответа» на пинги — хостер может закрывать ICMP; смотрите на остальные проверки.
- «Нет записи в …» — у вас нет прав на папку из `--dir`; запускайте с `sudo` или выберите другую.
- Системы не на `apt` (CentOS, Alpine): поставьте `fio curl python3 ffmpeg iproute2` вручную и запускайте без `--install`.
